# DEMO Waffles

Artisanal Belgian Waffle Co. website concept featuring:
- Dual-buffer seamless video loop hero (`hero-pour.mp4`)
- Dynamic background color sampling
- GSAP ScrollTrigger animations & 3D tilt effects
- Client-side multi-page SPA router
- Interactive custom Waffle Lab builder
- Slide-over bag & order management

## Deployment
Deployed on [Vercel](https://vercel.com).
